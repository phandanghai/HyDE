# Bundle: waybar

- **Package:** `waybar`
- **Mức độ:** 🔴 **Tier C — Cần HyDE core** (`~/.local/bin/hyde-shell` + `~/.local/lib/hyde` + `~/.local/share/hypr`). Không chạy độc lập.

> Thanh trạng thái. Module gọi script hyde-shell; nạp module từ ~/.local/share/waybar. Cần waybar.py + HyDE core.

## Cài đặt
```bash
sudo pacman -S --needed waybar
bash apply.sh
```
