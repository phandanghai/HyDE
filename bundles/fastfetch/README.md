# Bundle: fastfetch

- **Package:** `fastfetch`
- **Mức độ:** 🔴 **Tier C — Cần HyDE core** (`~/.local/bin/hyde-shell` + `~/.local/lib/hyde` + `~/.local/share/hypr`). Không chạy độc lập.

> config.jsonc gọi 'hyde-shell fastfetch logo' + 'hyprctl splash'. Kèm preset + script. Bỏ 2 dòng đó nếu dùng không cần HyDE.

## Cài đặt
```bash
sudo pacman -S --needed fastfetch
bash apply.sh
```
